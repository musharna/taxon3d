Difficulty tiers {% include "_scope_pill.html" %}

Each reconstruction task is tiered easy / moderate / hard by morphological complexity. The tables below aggregate the existing objective metrics (vs held-out real-plant GT) per tier — lower chamfer and higher F-score / structural are better. The headline: a well-behaved method should degrade monotonically easy → moderate → hard.
