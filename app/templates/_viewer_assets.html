This used to load model-viewer from ajax.googleapis.com, which made Google a single point of failure for the ONLY thing this site does. Measured 2026-08-08 with that host blocked: 6/6 elements upgraded and drew a canvas normally, 0/6 when blocked — the elements stayed in the DOM as inert boxes and NOTHING said why. Anyone on a network that blocks Google (China entirely; some corporate and university networks) got a 3D benchmark with no 3D. Same bytes, served from our own origin, so visitor payload is unchanged and no visitor IP is handed to a third party to render a model. Pin the version in the FILENAME so an upgrade is a visible, reviewable file swap rather than a silent CDN drift. #}
