How ranking works

Rank groups models whose 95% bootstrap CIs overlap into the same rank (they are not statistically separable). BT = Bradley–Terry score (Elo-scaled); the bar shows the 95% CI with the point estimate marked. Overall merges every paradigm into one BT-desc ordering for a single at-a-glance board — since paradigms are disconnected match components, that cross-paradigm ordering is a display convenience, not a statistical claim; select a paradigm tab for the rigorous, within-paradigm comparison.
