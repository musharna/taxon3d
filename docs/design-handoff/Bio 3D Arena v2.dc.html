How the arena works

Every ranking traces back to a simple, auditable loop: a real specimen, identical inputs, anonymous pairwise votes, and a statistical model that turns those votes into a score.

{{ st.num }}
{{ st.title }}
{{ st.body }}

The Bradley–Terry model

Each model earns a latent skill β. The probability one beats another is a logistic function of their rating gap — the same math behind chess Elo.

P(i > j) = 1 / (1 + e−(βi − βj))

Ratings are fit by maximum likelihood over all recorded pairs, then re-centred so the field mean sits near 1000.

Pairwise sampling

Pairs are drawn to maximise information: models with overlapping intervals are matched more often, so uncertainty collapses where the ranking is still contested. Both outputs are shown unlabelled, in a randomised left/right order, to remove position and brand bias.

Difficulty tiers

Tasks are graded Easy / Moderate / Hard by structural complexity — a single leaf versus a whole branching architecture. Tiering lets a model that only handles simple shapes be told apart from one that holds up under complexity.

Confidence & governance

A rating is marked firm only past 30 votes; below that it stays provisional. Every reference carries an explicit licence, and outputs can be held out of the pool without being deleted — kept on record for audit.
